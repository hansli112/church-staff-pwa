# 用安裝精靈建立同工助手

這份教學給沒有工程背景的教會同工。整個安裝在**你自己的 Google Cloud Shell** 完成，不需要在電腦安裝開發工具，也不需要 GitHub 帳號。

你只需要：

- 一個 Google 帳號（建立 Firebase 專案、存放資料）。
- 一個 Cloudflare 帳號（放網站）。
- 首位管理員可以收信的 email。

精靈只安裝**核心功能**：登入、同工管理、服事表。行事曆、照片辨識、通知與每日靈糧先不開啟，之後可由技術同工依[部署指南](deployment.md)另外設定。

## 開始之前

- 雲端資源、資料與帳單都屬於你們教會自己的帳號。精靈**不會綁定付費帳單，也不會升級付費方案**；如果平台要求付費或受組織政策限制，精靈會停下來說明原因。
- 打開 Cloud Shell 時，Google 會先問是否「信任存放區」：**一定要勾選再按「確認」**。畫面左上角若顯示「暫時模式」，代表沒勾到：請按 Cloud Shell 右上角的「⋮」，點選單裡打勾的「暫時模式」，再按「停用」。Cloud Shell 重新啟動並請你按「授權」後，回到安裝說明頁重新按「Open in Cloud Shell」，勾選「信任存放區」再照教學做。
- 接著會跳出 Google 官方的「授權 Cloud Shell」視窗，請按「**授權**」，不要按拒絕。
- 第一次會下載約 1–2 GB 的工具，需要幾分鐘到十幾分鐘。
- 精靈只建立**全新的專案**，不會接管或修改你們已經在用的網站或資料庫。
- 安裝紀錄存在 Cloud Shell 裡這份程式的 `.local/install/`，只有你自己看得到。中斷後可以接續，不會重複建立專案。

## 1. 啟動精靈

> **畫面左邊那一大排資料夾和檔案不用理它**，那是程式本身。整個安裝只會用到右邊這份教學，和下方的黑色終端機。

> **Cloud Shell 一打開可能就跳出「授權 Cloud Shell」視窗，請按「授權」。** 這是 Google 官方的視窗，讓 Cloud Shell 用你自己的 Google 帳號建立專案；按「拒絕」會讓後面的步驟無法進行。之後若再出現同樣的視窗，也一樣按「授權」。

**不用找程式在哪個資料夾**。按下方指令卡右上角的「在終端機執行」圖示（小終端機），然後在黑色終端機按一次 Enter。它會尋找已下載的程式；如果沒有，就從 GitHub 下載後啟動。只需做這一次，不要逐字輸入指令。

```sh
bash -c 'd=; [ -f scripts/start-installation.sh ] && d=$PWD; [ -z "$d" ] && s=$(find "$HOME" -maxdepth 7 -type f -path "*/church-staff-pwa*/scripts/start-installation.sh" -print -quit) && [ -n "$s" ] && d=${s%/scripts/start-installation.sh}; if [ -z "$d" ]; then d=$HOME/cloudshell_open/church-staff-pwa; mkdir -p $HOME/cloudshell_open && git clone -q --branch main --single-branch https://github.com/hansli112/church-staff-pwa.git "$d" || exit 1; fi; grep -q "pull --ff-only --quiet origin" "$d/scripts/start-installation.sh" || git -C "$d" pull -q --ff-only origin main; exec bash "$d/scripts/start-installation.sh"'
```

如果終端機顯示紅色錯誤，先停下來，不要重複按「執行」。

第一次會下載約 1.5 GB 的工具，終端機會顯示目前是第幾步和下載進度條，通常需要 3–10 分鐘。下載進度暫停不代表當機；若超過五分鐘完全不動，記下畫面上的錯誤訊息再求助，不必開第二個終端機。重新開啟教學時，只要再按同一張指令卡；程式檔案未被修改、也沒有待接續的安裝時，啟動工具會自動更新。

準備完成後，終端機會顯示一個私人連結。**只在你自己的瀏覽器開啟，不要分享給別人**；這個連結 15 分鐘內要開啟。第一次點開時 Google 會先確認你的帳號，畫面可能請你「再點一次」：回到 Cloud Shell 分頁，再點同一個連結就會開啟。

## 2. 連接帳號

在精靈頁面：

1. 按「連接 Google」，接著切到 Cloud Shell 分頁。出現「Authorize Cloud Shell」時按 **Authorize**，選這次要用的 Google 帳號。沒出現就回精靈再按一次「連接 Google」。精靈會顯示已連接的帳號；**不是你要用的帳號就先停下**，照精靈上的說明切換帳號後重開教學。
2. 按「連接 Cloudflare」，再按「開啟官方授權頁」。在 Cloudflare 官方網頁**輸入精靈顯示的代碼**（頁面說的「terminal」指的就是精靈），按 Continue。還沒登入的話，這時才會請你登入，登入後按 **Authorize**。看到「Authorization granted」就完成了，頁面上其他說明（例如 AI 工具）都不用理。代碼約 5 分鐘內有效，精靈會倒數；過期就再按一次「連接 Cloudflare」取得新代碼，不要授權舊代碼。
   - **還沒有 Cloudflare 帳號**：在登入頁按「Sign up」免費註冊，Cloudflare 會寄一封驗證信，點信裡的連結完成驗證。之後回到精靈，**重新按一次「連接 Cloudflare」**拿新的代碼。

兩邊的密碼都只在 Google 與 Cloudflare 官方網頁輸入，精靈不會看到。

## 3. 填寫教會資料

- **教會名稱、簡稱**：顯示在 App 和手機桌面圖示上。
- **網站名稱**：網址會是 `網站名稱.pages.dev`，同工用這個網址登入，所以取個好記的，例如 `hope-church-staff`。只能用英文小寫、數字和連字號（-），**建立後不能更改**。這個名稱如果已經被別的 Cloudflare 帳號用過，Cloudflare 會在後面自動加幾個字，實際網址以完成頁為準。
- **教會時區**：決定服事表的日期，台灣是 `Asia/Taipei`。
- **資料庫地區**：資料儲存的位置，台灣可選「台灣 · asia-east1」。**建立後不能直接更改。**
- **每週聚會**：每種聚會的名稱與固定星期。先填目前有的就好，裝好之後管理員可以在 App 的「我的」→「聚會設定」新增、改名、改星期或停用。
- **首位管理員**：姓名與 email。精靈不會要你設定密碼。

按「檢查並預覽安裝」。

## 4. 確認並開始安裝

仔細核對畫面上的新專案、資料地區與管理員 email，勾選兩個確認項目，再按「確認並開始安裝」。

安裝過程會依序建立專案、資料庫、登入功能、網站，並寄一封設定密碼信給管理員。請保持 Cloud Shell 分頁開啟。

### 如果顯示「稍後接續」

Google 可能還在建立資源，或已收到建立請求但沒回覆結果。**不要重新開始新的安裝**；等 3–5 分鐘後按「稍後接續安裝」，精靈會先讀回實際狀態，不會重送建立請求。

### 如果停在「待本人操作」

有些平台設定必須由本人在官方網頁確認，例如第一次啟用 Firebase 登入功能。畫面會顯示原因和「開啟官方設定頁」按鈕。在官方網頁完成後，回到精靈按「核對後接續安裝」。

從沒用過 Firebase 的 Google 帳號，會在「將 Firebase 加入新專案」這一步停下來，因為 Google 規定要本人同意 Firebase 條款。照畫面指示到 Firebase 官網，把 Firebase 加到精靈建好的「Church Staff」專案（不要另建新專案），回來按「核對後接續安裝」即可。

### 如果中途關掉了

重新執行第 1 步，連接**同一組** Google 與 Cloudflare 帳號，在「接續之前中斷的安裝」選擇原本的紀錄。精靈會先核對雲端實際狀態，不會另建專案。

## 5. 完成後驗收

1. 到管理員信箱找 Firebase 寄的英文信（主旨含「Reset your password」）。**這封信多半會在垃圾郵件**，找到後可標成「不是垃圾郵件」。用信中的連結設定密碼。
2. 開啟精靈顯示的網址，用管理員 email 和剛設定的密碼登入。
3. 到「服事表」按右上角鉛筆，再按右上角清單圖示「服事項目設定」，新增一個服事項目（例如「招待」），按 ✓ 儲存。
4. 到下方「我的」→「帳號管理」新增一位同工：設定牧區，並在該牧區的「參與服事」勾選剛才的服事項目。
5. 回「服事表」→ 鉛筆，在某個日期按「新增服事項目」替這位同工排班，重新整理後仍看得到。資料權限規則可能要幾分鐘才完全生效。

精靈完成頁也列了同樣的檢查項目。只是測試安裝的話，完成頁的「如何刪除」只列出這次建立的 Cloudflare 網站與 Google 專案：Cloudflare 刪除是立即永久；Google 專案關閉後約 30 天內仍可還原。

沒收到信時，在網站登入頁按「**忘記密碼？**」，輸入管理員 email 再寄一次。**不要另外建立管理員。**

## 6. 分享給同工、保存交接卡

- **分享給同工**：完成頁有一段可以直接貼到 LINE 群組的訊息。裡面的連結帶有 `?openExternalBrowser=1`，LINE 會改用手機的瀏覽器開啟；在 LINE 內建瀏覽器裡沒辦法加到主畫面，關掉後也常要重新登入。同工第一次開啟時，首頁會提示怎麼加到手機主畫面。
- **交接卡**：完成頁列出這個網站掛在哪個 Google 帳號、Cloudflare 帳號底下，以及專案 ID 與安裝識別碼。**請截圖或複製，存到教會的共用資料夾。**以後要更新、除錯或交接給別人都需要這些資料。

## 7. 更新到新版本

有新版本時，管理員在 App 的「我的」頁面會看到「有新版本可以更新」，列出這次改了什麼。更新方式：

1. 照第 1 步重新開啟精靈（同一張指令卡，它會自動下載最新版）。
2. 照第 2 步連接**當初安裝用的** Google 與 Cloudflare 帳號。不確定是哪一組，看交接卡。
3. 在「已經裝過了？更新到新版本」按「**尋找已安裝的網站**」，選你們的網站。
4. 核對網站網址，勾選確認，按「**開始更新**」。

更新**只換網站程式和資料存取規則**，同工帳號、服事表和所有資料都不會變。建置新版大約 10–20 分鐘，這段時間舊版照常可以用；中途停止或失敗也不會影響舊版，重新按「開始更新」即可。已經是最新版的話，精靈會直接告訴你，不會重新建置。

更新完成後，同工重新整理網頁，或把手機桌面上的 App 關掉重開，就會換到新版。

### 順便換教會 Logo、設定自訂網址

更新時展開「換教會 Logo、設定自訂網址（選填）」：

- **教會 Logo**：選一張圖片（PNG 或 JPG，正方形最好），再選底色。精靈會自動做出網站和手機桌面需要的各種尺寸，並顯示預覽。之後的更新會沿用這個 Logo；想換回來按「改回預設圖示」。手機上已經加到桌面的圖示不會自動換，要刪掉重新加一次。
- **自訂網址**：教會自己有網域（例如 `hope-church.org`）、而且有人能改 DNS 時才用。填一個子網域，例如 `staff.hope-church.org`；不能只填 `hope-church.org`。更新完成後，精靈會列出要新增的一筆 **CNAME** 記錄（名稱 `staff`、目標是原本的 `.pages.dev` 網址），請到網域註冊商或 Cloudflare 的 DNS 頁面加上。通常幾分鐘到幾小時生效，生效前繼續用原本的網址。

## 目前限制

- 這是第一版，雲端實際安裝流程還在驗證中，遇到問題請到專案 GitHub 開 issue，附上畫面上的錯誤說明（**不要貼上任何密碼、連結中的代碼或授權碼**）。本專案不提供客服或保證回應時間。
- 行事曆、照片辨識、通知與每日靈糧等選用功能，目前仍需技術同工依[部署指南](deployment.md)處理。版本更新、教會 Logo 與自訂網址見上面第 7 步。
