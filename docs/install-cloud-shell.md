# 用安裝精靈建立同工助手

這份教學給沒有工程背景的教會同工。整個安裝在**你自己的 Google Cloud Shell** 完成，不需要在電腦安裝開發工具，也不需要 GitHub 帳號。

你只需要：

- 一個 Google 帳號（建立 Firebase 專案、存放資料）。
- 一個 Cloudflare 帳號（放網站）。
- 首位管理員可以收信的 email。

精靈只安裝**核心功能**：登入、同工管理、服事表。行事曆、照片辨識、通知與每日靈糧先不開啟，之後可由技術同工依[部署指南](deployment.md)另外設定。

## 開始之前

- 雲端資源、資料與帳單都屬於你們教會自己的帳號。精靈**不會綁定付費帳單，也不會升級付費方案**；如果平台要求付費或受組織政策限制，精靈會停下來說明原因。
- 打開 Cloud Shell 時會先跳出 Google 官方的「授權 Cloud Shell」視窗，請按「**授權**」，不要按拒絕。
- 第一次會下載約 1–2 GB 的工具，需要幾分鐘到十幾分鐘。
- 精靈只建立**全新的專案**，不會接管或修改你們已經在用的網站或資料庫。
- 安裝紀錄存在 Cloud Shell 裡這份程式的 `.local/install/`，只有你自己看得到。中斷後可以接續，不會重複建立專案。

## 1. 啟動精靈

> **Cloud Shell 一打開可能就跳出「授權 Cloud Shell」視窗，請按「授權」。** 這是 Google 官方的視窗，讓 Cloud Shell 用你自己的 Google 帳號建立專案；按「拒絕」會讓後面的步驟無法進行。之後若再出現同樣的視窗，也一樣按「授權」。

**不用找程式在哪個資料夾。**按下方指令卡右上角的「在終端機執行」圖示（小終端機），然後在黑色終端機按一次 Enter。它會尋找已下載的程式；如果沒有，就從 GitHub 下載後啟動。只需做這一次，不要逐字輸入指令。

```sh
bash -c 's=$(find "$HOME" -maxdepth 7 -type f -path "*/church-staff-pwa/scripts/start-installation.sh" -print -quit); if [ -z "$s" ]; then d="$HOME/cloudshell_open/church-staff-pwa"; mkdir -p "$(dirname "$d")" && git clone --branch dev --single-branch https://github.com/hansli112/church-staff-pwa.git "$d" || exit 1; s="$d/scripts/start-installation.sh"; fi; exec bash "$s"'
```

目前精靈仍在 `dev` 分支驗收；合併到 `main` 後，教學會改用 `main`。如果終端機顯示紅色錯誤，先停下來，不要重複按「執行」。

第一次會下載約 1.5 GB 的工具，終端機會顯示目前是第幾步和下載進度條，通常需要 3–10 分鐘。下載進度暫停不代表當機；若超過五分鐘完全不動，記下畫面上的錯誤訊息再求助，不必開第二個終端機。重新開啟教學時，只要再按同一張指令卡；程式檔案未被修改、也沒有待接續的安裝時，啟動工具會自動更新。

準備完成後，終端機會顯示一個私人連結。**只在你自己的瀏覽器開啟，不要分享給別人**；這個連結 15 分鐘內要開啟，只能用一次。

## 2. 連接帳號

在精靈頁面：

1. 按「連接 Google」。若沒有反應，切回 Cloud Shell 分頁，看看有沒有授權提示。
2. 按「連接 Cloudflare」，再按「開啟官方授權頁」。在 Cloudflare 官方網頁登入，**核對頁面上的代碼和精靈顯示的一樣**，再按授權。

兩邊的密碼都只在 Google 與 Cloudflare 官方網頁輸入，精靈不會看到。

## 3. 填寫教會資料

- **教會名稱、簡稱**：顯示在 App 和手機桌面圖示上。
- **教會時區**：決定服事表的日期，台灣是 `Asia/Taipei`。
- **資料庫地區**：資料儲存的位置，台灣可選「台灣 · asia-east1」。**建立後不能直接更改。**
- **每週聚會**：每種聚會的名稱與固定星期。
- **首位管理員**：姓名與 email。精靈不會要你設定密碼。

按「檢查並預覽安裝」。

## 4. 確認並開始安裝

仔細核對畫面上的新專案、資料地區與管理員 email，勾選兩個確認項目，再按「確認並開始安裝」。

安裝過程會依序建立專案、資料庫、登入功能、網站，並寄一封設定密碼信給管理員。請保持 Cloud Shell 分頁開啟。

### 如果停在「待本人操作」

有些平台設定必須由本人在官方網頁確認，例如第一次啟用 Firebase 登入功能。畫面會顯示原因和「開啟官方設定頁」按鈕。在官方網頁完成後，回到精靈按「核對後接續安裝」。

### 如果中途關掉了

重新執行第 1 步，連接**同一組** Google 與 Cloudflare 帳號，在「接續之前中斷的安裝」選擇原本的紀錄。精靈會先核對雲端實際狀態，不會另建專案。

## 5. 完成後驗收

1. 到管理員信箱找 Firebase 寄的設定密碼信（也檢查垃圾郵件），用信中的連結設定密碼。
2. 開啟精靈顯示的網址，用管理員 email 和剛設定的密碼登入。
3. 試著新增一位同工、打開服事表。資料權限規則可能要幾分鐘才完全生效。

沒收到信時，到 Firebase Console 的 **Authentication → Users**，找到管理員 email，選擇寄送密碼重設信。**不要另外建立管理員。**

## 目前限制

- 這是第一版，雲端實際安裝流程還在驗證中，遇到問題請到專案 GitHub 開 issue，附上畫面上的錯誤說明（**不要貼上任何密碼、連結中的代碼或授權碼**）。本專案不提供客服或保證回應時間。
- 自訂網域、教會 Logo、選用功能與日後版本更新，目前仍需技術同工依[部署指南](deployment.md)處理。
