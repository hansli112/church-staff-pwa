# 教會服事表 App 安裝教學：程式小白也能自己架設，同工服事一目瞭然（附圖解）

排服事表、找同工、整理名單，常常卡在 LINE 群組和好幾份試算表之間。所以我為教會做了一個服事用的 App，現在整理成不會寫程式也能自己裝的版本，分享給需要的教會。

這篇教學寫給**沒有工程背景的教會同工**。整個安裝都在瀏覽器裡完成，不用在電腦上裝任何軟體，也不需要 GitHub 帳號。網站和資料都放在**你們教會自己的帳號**裡，不經過我。

---

## 這個 App 可以做什麼

【插入圖 00｜00-app-overview.png】
圖說：左邊是同工打開看到的首頁，右邊是服事表。首頁的「行事曆」要另外串接 Google 日曆，這一版還不包含（見下方說明）。畫面裡的教會和人名都是示範用的。

- **同工打開就看到自己接下來的服事**：哪一天、哪一場聚會、負責什麼，不用再去 LINE 群組裡翻。
- **服事表依聚會分頁**：主日、青年崇拜各一頁，每週誰負責什麼一目了然。
- **排服事的人直接在 App 裡排**：新增服事項目、指派同工，改完大家打開就是新的。
- **每位同工有自己的帳號**：管理員幫忙建立，同工登入後只會看到自己參與的聚會。
- **聚會可以自己調**：新增聚會、改星期幾、停用不再舉行的聚會，都在 App 裡完成。
- **可以加到手機桌面**：從桌面的圖示打開，用起來就像一般的 App。

另外還有**行事曆**（首頁顯示教會近期活動）、**每日靈糧**，以及**拍照匯入整季服事表**。這些要多串接其他服務，這一版先不包含，之後可以請懂技術的同工另外打開。

## 安裝前先準備

- **一個 Google 帳號**：用來建立存放資料的 Firebase 專案。**用個人的 Gmail 就可以**；網站會掛在這個帳號底下，裝完精靈會給你一張「交接卡」記下來。
- **一個 Cloudflare 帳號**：用來放網站，免費註冊即可（cloudflare.com）。
- **首位管理員能收信的 email**：安裝完會寄一封設定密碼的信到這裡。
- **一台電腦**：用 Chrome 瀏覽器最順。第一次安裝抓 30 分鐘到 1 小時比較保險。

幾個你可能會擔心的問題：

- **要付錢嗎？** 安裝精靈**不會綁定信用卡，也不會升級付費方案**。如果平台要求付費，或你們的組織帳號有限制，精靈會停下來說明原因，不會自己往下做。
- **會動到我們現有的網站嗎？** 不會。精靈只建立**全新的專案**，不會接管或修改你們已經在用的網站或資料庫。
- **密碼會被看到嗎？** Google 和 Cloudflare 的密碼都只在它們的**官方網頁**輸入，精靈看不到。

## 第一步：打開 Cloud Shell

Cloud Shell 是 Google 免費提供、開在瀏覽器裡的一台小電腦。安裝精靈就在這裡面執行。

1. 打開專案頁面：https://github.com/hansli112/church-staff-pwa
2. 在頁面最上面「不會寫程式？用安裝精靈」下面，按藍色的「**Open in Google Cloud Shell**」按鈕。

【插入圖 01｜01-open-in-cloud-shell.png】
圖說：在專案頁找到這顆藍色按鈕。

3. Google 會問要不要「信任存放區」。**一定要先勾選「信任存放區」，再按「確認」。**

【插入圖 02｜02-trust-repo.png】
圖說：先勾選「信任存放區」，再按「確認」。這一步最容易漏掉。

4. 接著跳出 Google 官方的「授權 Cloud Shell」視窗，請按「**授權**」，不要按拒絕。之後如果再看到同樣的視窗，也一樣按「授權」。

【插入圖 03｜03-authorize-cloud-shell.png】
圖說：這是 Google 官方的視窗，讓 Cloud Shell 用你自己的帳號建立專案。

### 如果左上角出現「暫時模式」

沒勾到「信任存放區」的話，Cloud Shell 左上角會顯示「**暫時模式**」，精靈就沒辦法幫你建立專案。處理方式：

1. 按右上角的「⋮」，點選單裡**打勾的「暫時模式」**。

【插入圖 04｜04-ephemeral-menu.png】
圖說：左上角有「暫時模式」字樣，就從右上角「⋮」把它關掉。

2. 按「**停用**」。

【插入圖 05｜05-ephemeral-disable.png】
圖說：按「停用」，Cloud Shell 會重新啟動。

3. Cloud Shell 重新啟動、請你按「授權」之後，回到專案頁**重新按一次**「Open in Google Cloud Shell」，這次記得勾選「信任存放區」。

## 第二步：啟動安裝精靈

Cloud Shell 打開後像一個寫程式的軟體，**左邊一大排資料夾和檔案不用理它**。只看右側的「教學課程」面板，和下方的黑色終端機。

1. 右側教學第一頁最下面有藍色的「**啟動**」按鈕，按下去到「1. 啟動精靈」這一頁。
2. 找到灰色指令卡右上角的「**在終端機執行**」小圖示（像一個小螢幕）按下去。
3. 在下方黑色的終端機裡按一次 **Enter**。

【插入圖 06｜06-run-in-terminal.png】
圖說：按指令卡右上角的小終端機圖示，不用自己打指令。

> **只要按一次**，不要逐字輸入指令。如果終端機出現紅色的錯誤訊息，先停下來，不要一直重複按。

4. 第一次會下載約 **1.5 GB** 的工具，終端機會顯示現在是第幾步（共 4 步）和下載進度條，通常要 **3–10 分鐘**。

【插入圖 07｜07-terminal-downloading.png】
圖說：下載 Flutter 是最久的一步，進度條停住一下是正常的。

5. 準備好後，終端機會顯示一個**私人連結**。點這個連結打開安裝精靈。

【插入圖 08｜08-terminal-link.png】
圖說：連結只給你自己用，不要分享（圖中已遮住）。連結 15 分鐘內要打開。

### 如果畫面說「還差一步」

第一次點連結時，Google 會先確認你的帳號，所以可能會看到這個提示：

【插入圖 09｜09-open-again.png】
圖說：這是正常的。回到 Cloud Shell 分頁，再點一次同一個連結就好。

## 第三步：連接 Google 和 Cloudflare 帳號

精靈打開後，第一區是「連接你的帳號」。

【插入圖 10｜10-connect-accounts.png】
圖說：先按「連接 Google」，再按「連接 Cloudflare」。

### 連接 Google

1. 按「**連接 Google**」，接著切到 Cloud Shell 分頁。
2. 出現「Authorize Cloud Shell」時按 **Authorize**，選你這次要用的 Google 帳號。沒出現的話，回精靈再按一次「連接 Google」。
3. 精靈會顯示「已連接：你的 email」。**如果不是你要用的帳號，先停下來**，照精靈上的說明換帳號後再重新開始。

### 連接 Cloudflare

1. 按「**連接 Cloudflare**」，精靈會顯示一組**代碼**，再按「**開啟官方授權頁**」。

【插入圖 11｜11-cloudflare-code.png】
圖說：記下這組代碼，再按「開啟官方授權頁」。精靈會倒數代碼剩多少時間。

2. 在 Cloudflare 官方網頁，把**精靈顯示的代碼**輸入到框框裡，按 **Continue**。還沒登入的話，這時才會請你登入（可以用 Google 帳號登入）。登入後按 **Authorize**。

【插入圖 12｜12-cloudflare-enter-code.png】
圖說：頁面上說的「terminal」指的就是安裝精靈，把精靈上的代碼填進來。

3. 看到「Authorization granted」就完成了。頁面上其他英文說明（例如 AI 工具）都不用理，這個分頁可以關掉，回到精靈。

【插入圖 13｜13-cloudflare-granted.png】
圖說：Cloudflare 授權成功的畫面。

> 代碼大約 5 分鐘內有效。如果過期了，回精靈再按一次「連接 Cloudflare」拿新代碼，**不要授權舊的代碼**。

> **還沒有 Cloudflare 帳號？** 在登入頁按「Sign up」免費註冊，Cloudflare 會寄一封驗證信，點信裡的連結完成驗證。之後回到精靈，**重新按一次「連接 Cloudflare」**拿新的代碼再做一次。

兩邊都連好後會像這樣：

【插入圖 14｜14-accounts-connected.png】
圖說：Google 和 Cloudflare 都顯示「已連接」。

## 第四步：填寫教會資料

【插入圖 15｜15-church-settings.png】
圖說：填完後按「檢查並預覽安裝」。

- **教會／App 名稱、桌面圖示簡稱**：會顯示在 App 和手機桌面圖示上。
- **網站名稱**：網址會是「網站名稱.pages.dev」，同工要用這個網址登入，所以取個好記的，例如 `grace-church-staff`。只能用英文小寫、數字和連字號（-），**建立後不能改**。如果這個名稱已經被別人用過，Cloudflare 會在後面自動加幾個字，實際網址以完成頁為準。
- **教會時區**：決定服事表的日期，台灣是 `Asia/Taipei`。
- **資料庫地區**：資料存放的地方，台灣選「台灣 · asia-east1」。**建立後不能改**，請確認再按。
- **每週聚會**：每一種聚會的簡稱、全名和固定星期幾，例如「主日／主日崇拜／星期日」。有好幾種聚會就按「新增一種聚會」。先填目前有的就好，裝好之後可以在 App 裡隨時新增或修改。
- **首位管理員**：姓名和 email。這裡**不用設定密碼**，裝好後會用官方信件設定。

按「**檢查並預覽安裝**」。

## 第六步：完成後的驗收

全部跑完後，精靈會顯示「網站已發布，接著完成登入驗收」，並列出 6 個檢查項目。**6 項都做到，才算安裝成功。**做完再照第 7、8 項分享給同工、保存交接卡。

【插入圖 21｜21-complete-checklist.png】
圖說：照順序打勾。「開啟你們的同工助手」就是你們教會的網站。

### 1–3. 設定管理員密碼並登入

1. 到管理員信箱找設定密碼的信：寄件者會顯示你們的教會名稱，主旨裡有一串 church- 開頭的專案代號，這是正常的，不是詐騙信。**這封信多半會被丟到垃圾郵件**，找到後可以標成「不是垃圾郵件」。
2. 點信裡的連結設定密碼。
3. 打開網站，用管理員 email 和剛設定的密碼登入。

> 剛裝好就登入失敗的話，等 5 分鐘再試，資料權限要一點時間才會生效。沒收到信的話，**不要另外建立管理員**，在網站登入頁按「**忘記密碼？**」，輸入管理員 email 再寄一次。

### 7. 分享給同工

驗收完成後，把完成頁「分享給同工」那段訊息複製起來，貼到同工的 LINE 群組就好。

【插入圖 32｜32-share-message.png】
圖說：按「複製這段訊息」，直接貼到 LINE。

訊息裡的連結後面帶了 `?openExternalBrowser=1`，**請不要刪掉**。LINE 看到它就會改用手機的 Safari 或 Chrome 開啟；如果留在 LINE 裡面開，就沒辦法加到手機主畫面，關掉之後也常常要重新登入。

同工第一次登入後，首頁會出現「加到手機主畫面」的提示，照著做，之後就能像 App 一樣從桌面點開：

- **iPhone**：用 Safari 開啟，按下方工具列的「分享」→「加入主畫面」→「加入」。下方只有網址列、看不到分享圖示的話（iOS 26 預設的版面），先按網址列右邊的「⋯」，再按「分享」。
- **Android**：用 Chrome 開啟，按首頁提示的「安裝到手機」；沒有這顆按鈕的話，按右上角「⋮」→「安裝應用程式」或「加到主畫面」。

### 8. 保存交接卡

完成頁最下面有一張「交接卡」，列出這個網站掛在哪個 Google 帳號、Cloudflare 帳號底下，還有專案 ID 等資料。

【插入圖 33｜33-handoff-card.png】
圖說：按「複製交接資料」，或直接截圖。

**請把它存到教會的共用資料夾**（例如雲端硬碟或教會的 LINE 記事本）。之後要更新網站、找人幫忙除錯，或是換人負責，都會需要這些資料。

## 常見問題

**Q：中途不小心關掉了怎麼辦？**
重新做「第二步」，連接**同一組** Google 和 Cloudflare 帳號，在「接續之前中斷的安裝」選原本的紀錄。精靈會先核對雲端上的實際狀態，不會另外建一個專案。

**Q：只是想先試試看，裝完要怎麼刪？**
完成頁最下面有「這只是測試安裝？如何刪除」，只會列出這次建立的兩個項目。

【插入圖 34｜34-cleanup-steps.png】
圖說：先刪 Cloudflare 網站，再關閉 Google 專案。正式使用的站請不要刪。

- **Cloudflare 網站**：打開網站專案頁，按上方「Settings」→ 右側「General」→ 最下方紅字「Delete」，輸入網站名稱確認。**立即永久刪除。**

【插入圖 35｜35-cloudflare-delete.png】
圖說：Settings → General → Delete。

- **Google 專案**：打開專案設定頁，按上方「Shut down」，輸入專案 ID 後按「Shut down anyway」。Google 會保留約 **30 天**才永久刪除，這段期間還能還原。

【插入圖 36｜36-google-shutdown.png】
圖說：輸入畫面上顯示的專案 ID，再按「Shut down anyway」。

**Q：有新版本怎麼更新？**
有新版本時，管理員在 App 的「我的」頁面會看到「有新版本可以更新」。更新方式跟安裝差不多：

1. 照「第一步」「第二步」重新打開安裝精靈。
2. 照「第三步」連接**當初安裝用的** Google 和 Cloudflare 帳號（不確定的話看交接卡）。
3. 在「已經裝過了？更新到新版本」按「**尋找已安裝的網站**」，選你們的網站。
4. 勾選確認，按「**開始更新**」，大約 10–20 分鐘。

更新**只會換網站程式**，同工帳號、服事表和所有資料都不會變。更新期間舊版照常可以用，中途失敗也不會影響舊版。

**Q：想換成教會 Logo，或用自己的網址？**
在更新時展開「換教會 Logo、設定自訂網址（選填）」就可以設定，不用另外找懂技術的人：

- **教會 Logo**：選一張圖片（正方形最好）和底色，精靈會自動做好各種尺寸。手機桌面上已經加的圖示要刪掉重新加，才會換成新的。
- **自訂網址**：教會自己有網域、而且有人能改 DNS 時才需要。填像 `staff.你們的網域` 這樣的網址，更新完成後照畫面上的說明加一筆 DNS 記錄即可。

**Q：要新增聚會（例如禱告會），或聚會改到別天？**
管理員到 App 的「**我的**」→「**聚會設定**」就可以新增、改名稱、改星期幾，或停用不再舉行的聚會，改完按右上角 ✓ 儲存，所有人的 App 下次打開就會換成新的設定。

【插入圖 37｜37-service-settings.png】
圖說：「聚會設定」畫面。關掉開關就是停用；按住右邊的把手可以調整服事表分頁的順序。

- 改星期：已經排好的日期不會搬動，從下一個還沒排的那週開始用新的星期。
- 停用：不再出現在服事表上，舊資料都會保留，之後可以再開啟。

**Q：想加行事曆、每日靈糧等其他功能？**
這些目前還需要懂技術的同工照專案裡的部署指南處理。
