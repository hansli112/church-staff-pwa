# 馬大別忙

多教會共用的同工服事表工具（代管版）。設計見 [`docs/design.md`](docs/design.md)，資料模型與權限見 [`docs/data-model.md`](docs/data-model.md)。

> 開發中。自架版（church-staff-pwa）在其他分支。

## 開發

安全規則測試（需要 Java 與 Node）：

```sh
cd firestore-tests && npm install && npm test
```
