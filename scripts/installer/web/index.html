確認這次安裝

確認後會在你的帳號建立雲端資源。帳號與網站名稱已先檢查；Google 的專案額度、條款與組織政策沒有事先查詢的方式，會在最前面建立專案、啟用 Firebase 時確認；不通過就停下，不會繼續建立資料庫、網站或管理員。精靈不開通付費方案。

停止不會刪除已建立的專案或資料。再次接續前，精靈會核對實際狀態。

4

安裝進度

首次下載工具與建置可能需要一段時間。請保留 Cloud Shell 分頁；不需重新按建立專案。

    安裝識別碼：

    進度存在你自己的 Cloud Shell 私有目錄，不在此瀏覽器的 localStorage。

    網站已發布，接著完成登入驗收

    開啟你們的同工助手
    1. 到指定管理員信箱找 Firebase 設定密碼信，也檢查垃圾郵件。
    2. 使用信件內的官方連結設定密碼，再以該 email 登入網站。
    3. 確認可管理同工、開啟服事表。資料規則可能需要幾分鐘才完全生效。

    寄信步驟成功只代表平台接受寄送請求，不保證送達。若沒有收到，請由 Firebase 官方 Authentication 使用者頁面重新寄送。
