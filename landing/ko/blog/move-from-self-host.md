직접 설치하는 church-staff-pwa는 이제 업데이트되지 않아요. 마르다의 쉼표는 같은 봉사표의 온라인 버전이라 Firebase나 Cloudflare를 직접 관리할 필요가 없고, 휴대폰 앱도 있어요. 이 글은 교회 사이트를 처음 설치한 관리자를 위한 것이고, 10분쯤 걸려요.

옮길 때는 예전 사이트의 데이터를 읽기만 하고, 바꾸거나 지우지 않아요. 다 옮기기 전까지는 예전 사이트를 그대로 쓰면 돼요.

컴퓨터로 하세요. 이전용 파일을 컴퓨터에서 만들고 내려받기 때문에, 같은 컴퓨터에서 올리는 게 가장 편해요.

## 옮겨 오는 것

- 멤버의 이름, 이메일, 권한, 속한 예배와 소그룹
- 모든 봉사표, 특별 순서, 멤버 순서
- 예배, 담당, 자주 쓰는 특별 순서

로그인 비밀번호, 푸시 알림, LINE 알림, 매일 묵상, 캘린더 연결은 옮겨 오지 않아요. 멤버가 같은 이메일로 마르다의 쉼표에 로그인하면 자기 데이터와 이어져요. 캘린더는 옮긴 뒤에 다시 연결하세요.

## 1. 이전용 파일 만들기

사이트를 설치한 Google 계정으로 [Cloud Shell을 여세요](https://shell.cloud.google.com/cloudshell/editor?cloudshell_git_repo=https%3A%2F%2Fgithub.com%2Fhansli112%2Fchurch-staff-pwa&cloudshell_git_branch=main&cloudshell_workspace=.&cloudshell_tutorial=docs%2Fmove-to-martha.md&show=terminal). 저장소를 신뢰할지 묻는 창이 나오면 신뢰에 체크하고 확인을 누르세요. 이어서 Cloud Shell 승인을 묻는 창이 나오면 승인을 누르세요. Google의 공식 창으로, Cloud Shell이 내 계정으로 예전 사이트의 데이터를 읽을 수 있게 해 줘요. 같은 창이 또 나와도 승인을 누르면 돼요.

오른쪽에 옮기는 방법(번체 중국어)이 열리면, 1단계 명령어 오른쪽 위의 터미널 아이콘을 누르고 아래 터미널에서 Enter를 한 번 누르세요.

다 되면 멤버가 몇 명, 봉사표가 몇 개인지 나와요. 숫자를 확인하세요.

- `找到好幾個同工助手的專案`(프로젝트가 여러 개)라고 나오면, 명령어 끝의 `--out move.json` 앞에 `--project 프로젝트ID`를 붙여 다시 실행하세요. 프로젝트 ID는 목록에 나온 것 중 하나예요.
- `找不到同工助手的專案`(찾을 수 없음)이나 `讀不到`(읽을 수 없음)라고 나오면, 대개 로그인한 Google 계정이 달라서예요. 사이트를 설치한 계정으로 바꿔서 다시 해 보세요.

## 2. 이전용 파일 내려받기

터미널에서 실행하세요.

```sh
cloudshell download "$HOME/move.json"
```

브라우저에 `move.json`이 내려받아져요. 멤버의 이름과 이메일이 들어 있으니 단톡방에 올리거나 다른 사람에게 보내지 마세요. 다 올리고 나면 지우세요.

## 3. 마르다의 쉼표에 올리기

1. <span data-from-app="hide">[웹 버전](/home)을 열고 </span>로그인하세요. Google이든 이메일이든 괜찮아요. 이메일로 가입했다면 먼저 인증 메일의 링크를 여세요.
2. ‘교회에 가입하기’에서 ‘새 교회 만들기’를 고르고, 맨 아래의 ‘구버전에서 옮겨 오기’를 누르세요.
3. ‘이전용 파일 선택’을 누르고, 내려받은 `move.json`을 고르세요.
4. 멤버와 봉사표 수를 확인하고 ‘교회 이름’을 넣으세요.
5. ‘이 사람이 나예요(선택)’에서 자신을 고르면 예전 사이트의 봉사와 권한을 이어받아요. 로그인한 이메일과 같은 사람은 처음부터 골라져 있어요.
6. ‘교회 만들고 옮겨 오기’를 누르세요. 파일을 올린 사람이 새 교회의 관리자가 돼요.

## 4. 멤버 가입시키기

옮겨 온 멤버는 처음에 아직 로그인하지 않은 사람으로 나와요. ‘설정’ → ‘초대’에서 초대 링크를 만들어 멤버 단톡방에 보내세요.

- 예전 사이트와 같은 이메일로 로그인한 멤버에게는 교회에 가입할지 묻는 화면이 나와요. ‘가입’을 누르면 자기 봉사표가 그대로 이어져요.
- 예전 비밀번호는 쓸 수 없어요. 이메일과 비밀번호로 로그인하던 사람은 같은 이메일로 새로 가입하거나 Google로 로그인하세요.
- 예전 사이트에 이메일이 없던 멤버는, 초대 링크로 가입할 때 봉사표와 같은 이름을 넣으면 본인이 맞는지 물어봐요.
- 이메일이 바뀐 사람은 관리자가 그 사람의 페이지에서 ‘로그인 전 정보 합치기’를 누르세요.

## 옮긴 다음

옮기기는 한 번만 해요. 그 뒤에 예전 사이트에서 바꾼 봉사표는 넘어오지 않으니, 날짜를 정해서 그날부터 마르다의 쉼표를 쓰자고 멤버에게 알려 주세요.

예전 사이트는 백업으로 남겨 둬도 되고, Firebase와 Cloudflare 콘솔에서 직접 지워도 돼요.
