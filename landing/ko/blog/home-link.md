관리자는 모든 멤버의 홈 맨 위에 링크를 하나 둘 수 있어요. 헌금 페이지, 주보, 매일 묵상 같은 것이에요. "설정" → "교회 정보" → "홈 링크"에서 설정해요.

## 고정 링크

제목, 설명(선택), 링크를 입력하고 "저장"을 누르면 돼요.

## 매일 자동으로 바꾸기

매일 묵상처럼 날마다 새 내용이 있다면 "내용 주소(JSON)"를 입력하세요. 정한 시각에 하루 한 번 가져와서 그날의 제목, 설명, 링크로 바꿔요.

이 주소는 다음과 같은 JSON을 돌려줘야 해요.

```json
{
  "date": "2026-11-19",
  "title": "매일의 양식",
  "body": "하나님의 말씀이 날마다 힘이 되기를",
  "link": "https://example.org/daily/2026-11-19"
}
```

- 항목은 `date`, `title`, `body`, `link` 네 개뿐이에요.
- `date`는 교회 시간대 기준 오늘이고, 형식은 `YYYY-MM-DD`예요. 오늘이 아니면 아직 오늘 내용이 없는 것으로 봐요.
- `title`은 비울 수 없고 30자까지 보여요. `body`는 비워도 되고 120자까지 보여요.
- `link`와 내용 주소 모두 `https://`여야 해요.
- 상대 사이트는 5초 안에 응답해야 하고, 내용은 64KB 이하여야 해요.

가져오지 못하거나 형식이 맞지 않으면 페이지에 이유가 나와요. "지금 업데이트"로 다시 시도할 수 있어요.

이런 주소는 보통 n8n, Make 또는 직접 만든 프로그램으로 만들어요. 만들 사람이 없다면 고정 링크로 충분해요.
