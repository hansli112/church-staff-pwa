管理者は、全員のホームのいちばん上にリンクをひとつ置けます。献金のページ、週報、毎日のデボーションなどです。「設定」→「教会情報」→「ホームのリンク」で設定します。

## 固定のリンク

タイトル、説明（任意）、リンクを入れて「保存」を押します。

## 毎日内容を自動で更新

毎日のデボーションのように毎日新しい内容があるなら、「内容の URL（JSON）」を入れてください。設定した時刻に毎日一回取得し、その日のタイトル・説明・リンクに置き換えます。

この URL は次のような JSON を返す必要があります。

```json
{
  "date": "2026-11-19",
  "title": "日々の糧",
  "body": "神のことばが毎日の力となりますように",
  "link": "https://example.org/daily/2026-11-19"
}
```

- 項目は `date`、`title`、`body`、`link` の四つだけです。
- `date` は教会のタイムゾーンでの今日、`YYYY-MM-DD` の形式です。今日でなければ、今日の内容はまだないものとします。
- `title` は空にできず、30 文字まで表示されます。`body` は空でもよく、120 文字まで表示されます。
- `link` と内容の URL はどちらも `https://` です。
- 相手のサイトは 5 秒以内に応答し、内容は 64 KB 以内です。

取得できないときや形式が違うときは、ページに理由が表示されます。「今すぐ更新」で再試行できます。

こうした URL は、たいてい n8n や Make、自分で書いたプログラムで作ります。書ける人がいなければ、固定のリンクで十分です。
