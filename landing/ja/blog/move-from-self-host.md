自前で立てる church-staff-pwa は、もう更新されません。マルタ、ひと休みは同じ奉仕表のオンライン版で、Firebase や Cloudflare を自分で管理する必要がなく、スマホのアプリもあります。この記事は、教会のサイトを立てた管理者の方向けです。10分ほどで終わります。

移行では古いサイトのデータを読むだけで、変更や削除はしません。移行が終わるまでは、これまでどおり古いサイトを使ってください。

パソコンで作業してください。移行ファイルはパソコン上で作ってダウンロードするので、同じパソコンからアップロードするのがいちばん簡単です。

## 移行されるもの

- メンバーの名前、メールアドレス、権限、所属する集会と小グループ
- すべての奉仕表、特別行事、メンバーの並び順
- 集会、担当、よく使う特別行事

ログインのパスワード、プッシュ通知、LINE 通知、毎日のデボーション、カレンダーの連携は移行されません。メンバーは同じメールアドレスでマルタ、ひと休みにログインすれば、自分のデータにつながります。カレンダーは移行後にもう一度連携してください。

## 1. 移行ファイルを作る

サイトを立てたときの Google アカウントで [Cloud Shell を開きます](https://shell.cloud.google.com/cloudshell/editor?cloudshell_git_repo=https%3A%2F%2Fgithub.com%2Fhansli112%2Fchurch-staff-pwa&cloudshell_git_branch=main&cloudshell_workspace=.&cloudshell_tutorial=docs%2Fmove-to-martha.md&show=terminal)。右側に移行の手順（繁体字中国語）が開くので、手順1のコマンドの右上にあるターミナルのアイコンをクリックし、下のターミナルで Enter を一度押します。

終わると、メンバーが何人、奉仕表が何件あったかが表示されます。数を確かめてください。

- `找到好幾個同工助手的專案`（プロジェクトが複数見つかった）と出たら、コマンドの最後の `--out move.json` の前に `--project プロジェクトID` を足してもう一度実行します。プロジェクト ID は一覧に出たもののどれかです。
- `找不到同工助手的專案`（見つからない）や `讀不到`（読めない）と出たら、たいていはログインしている Google アカウントが違います。サイトを立てたアカウントに切り替えて、もう一度試してください。

## 2. 移行ファイルをダウンロードする

ターミナルで次を実行します。

```sh
cloudshell download "$HOME/move.json"
```

ブラウザに `move.json` がダウンロードされます。メンバーの名前とメールアドレスが入っているので、グループに送ったり、人に渡したりしないでください。アップロードが終わったら削除してください。

## 3. マルタ、ひと休みにアップロードする

1. <span data-from-app="hide">[Web版](/home)を開いて</span>ログインします。Google でもメールアドレスでもかまいません。メールアドレスで登録した場合は、先に確認メールのリンクを開いてください。
2. 「教会に参加する」で「新しい教会を作成」を選び、いちばん下の「旧バージョンから移行」をタップします。
3. 「移行ファイルを選択」をタップし、ダウンロードした `move.json` を選びます。
4. メンバーと奉仕表の数を確かめます。「これは自分です（任意）」で自分を選ぶと、古いサイトでの奉仕と権限を引き継げます。
5. 「教会を作成して移行」をタップします。アップロードした人が新しい教会の管理者になります。

## 4. メンバーに参加してもらう

移行されたメンバーは、はじめは未ログインとして並びます。「設定」→「招待」で招待リンクを作り、メンバーのグループに送ってください。

- 古いサイトと同じメールアドレスでログインしたメンバーには、教会に参加するかどうかが表示されます。「参加」をタップすると、自分の奉仕表がそのままつながります。
- 古いパスワードは使えません。メールアドレスとパスワードでログインしていた人は、同じメールアドレスで新しく登録するか、Google でログインしてください。
- 古いサイトでメールアドレスがなかったメンバーは、招待リンクで参加するときに奉仕表と同じ名前を入れると、自分かどうかを聞かれます。
- メールアドレスが変わった人は、管理者がその人のページで「未ログインのデータを統合」をタップします。

## 移行のあと

移行は一度だけです。そのあと古いサイトで変えた奉仕表は移りません。日にちを決めて、その日からマルタ、ひと休みを使うようメンバーに伝えてください。

古いサイトはバックアップとして残しておいても、Firebase と Cloudflare のコンソールで自分で削除してもかまいません。

このあとの設定は、[はじめての方へ：教会を作成して、メンバーを招待する](/ja/blog/getting-started/)と[奉仕を割り当てる：数週間まとめて組み、ドラッグで入れ替える](/ja/blog/plan-weeks/)をご覧ください。
